# LourahJS Documentation  
A Lightweight JavaScript Framework for Android and Beyond

Welcome to the official documentation of **LourahJS**, a modular JavaScript framework designed to run on Android and provide high‑level abstractions for UI, system access, and application logic.

This documentation is organized into clear sections, each covering a specific part of the framework.  
Whether you're building Android UIs, handling internationalization, or exploring advanced modules, this site provides everything you need.

---

## 🚀 What is LourahJS?

LourahJS is a lightweight runtime and toolkit that allows developers to:

- write Android applications using JavaScript  
- build declarative UIs  
- access Android APIs dynamically  
- use symbolic keys and vocabulary‑based i18n  
- extend the system with modular components  

It is designed to be:

- **simple** — minimal boilerplate  
- **expressive** — declarative UI and DSLs  
- **modular** — each subsystem is independent  
- **powerful** — full access to Android APIs
